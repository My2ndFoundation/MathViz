## 0. 这个工具在整条线里的位置

前三个工具里，你一直在**调**控制器：调增益、看极点往哪走、量相位裕度还剩多少。这一个把这件事翻过来：

> **你不再设计控制器。你只说明「你想要什么」和「你相信谁」，控制器是算出来的。**

- **LQR** 回答「怎么动」：你给出代价的权重（求快还是省力），最优增益由 Riccati 方程解出来。
- **卡尔曼** 回答「你以为自己在哪」：你给出噪声的统计（模型多可信、传感器多可信），最优增益由同一类方程解出来。
- **分离原理** 说这两件事**可以分开设计**——这是个定理，不是巧合。
- 而它的代价是诚实的收尾：**LQG 没有保证的鲁棒裕度**。

被控对象仍然是那根倒立摆，`x = [θ, ω]ᵀ`，`u` 是枢轴力矩，线性化后

    ẋ = A x + B u,  A = [[0, 1], [g/L, −c]],  B = [0, 1/(mL²)]ᵀ

开环极点仍是那对 ±√(g/L)（含阻尼时略偏），读数区继续挂着它。

## 1. 技术约定

沿用控制论三部曲 §0.3：定步长 RK4（`h = 1/2000 s`）子步进、控制器离散零阶保持、饱和显式可见、每页靠积分器自走（§8 出路①）、种子不加 `drive`、`frame()` 用引擎标准兜底。

**Riccati 方程必须在页内实时解**，不能预先算好塞进常数表——滑杆一动，`K` 与 `L` 就要跟着变，这正是「控制器是算出来的」这句话的兑现。二阶系统可用稳定特征向量法（Hamiltonian 矩阵的稳定子空间）或迭代法；**无论哪种，都要在读数区给出残差** ‖AᵀP + PA − PBR⁻¹BᵀP + Q‖，让「解出来了」这件事可核对。

## 2. 页签

### ① LQR：你调的是代价，不是增益 `lqr`

- **画**：复平面在 x·y（与工具 B ①同一张图），**代价比 q/r 沿 z 轴**——闭环极点随代价比划出一族曲线。这与工具 B ①的根轨迹是刻意的呼应：那里第三根轴是**增益**（你手动扫的），这里是**代价比**（你说明偏好、增益自己出来）。
- 两根滑杆：`q`（状态代价，求快）与 `r`（控制代价，省力）。滑动时 `K = R⁻¹BᵀP` 实时重算，闭环极点在平面上移动，同屏小窗给出当前 `K` 的 θ(t) 与 u(t)。
- **对照**：同屏放一个手调 `K_manual` 的解，画出两者的累计代价 ∫(xᵀQx + ruᵀu)dt。手调那条**要么更慢、要么更费力**，总有一项输——这是「最优」二字的可核对含义，而不是形容词。
- **顿悟视角** `沿代价比俯视`：极点被代价函数选出来的那条路径。
- **tips**：你没有碰增益。你只说了更在乎快还是更在乎省力，增益自己出来了。

### ② 卡尔曼增益 = 两个不确定度的加权 `gain`

- **画**：四条 θ 的时间曲线——真值（slate）、含噪测量（orange，撕碎的）、纯模型预测（violet，慢慢漂走）、卡尔曼融合（emerald，跟得上且干净）。
- 两根滑杆：过程噪声 `σ_w`（模型有多不可信）与测量噪声 `σ_v`（传感器有多不可信）。**读数区常驻卡尔曼增益** `K_f`，并用标量直觉写明 `K = P/(P+R)`。
- **顿悟**：`σ_v` 大 → `K_f → 0`，它选择相信模型；`σ_w` 大 → `K_f → 1`，它选择相信测量。**卡尔曼不是滤波技巧，是「该信谁」的定量答案。**
- 与工具 A ④直接接续：那里的观测器增益是手调的（极点随便配在 −8），这里是由噪声统计**算出来的**。tips 要点破这层关系。

### ③ 协方差的呼吸 `covariance`

- **画**：相平面 (θ, ω) 上的协方差椭圆，**沿 z 轴按时间排开**。预测步让椭圆**沿动力学拉伸并长大**，更新步让它**沿测量方向收缩**——一呼一吸。
- **顿悟**：只测 θ、不测 ω，椭圆本该只在 θ 方向被压扁；但动力学的耦合会把这份「确定」**传播**到 ω 上——**这就是为什么测不到的量也能估出来**。把 A 的耦合项调零，椭圆在 ω 方向就再也不收缩了，这条要能当场演示。
- **顿悟视角** `相平面正视`看椭圆形状，`侧视`看它沿时间的呼吸。

### ④ 分离原理，以及它的代价 `separation`

- **画**：把 LQR 状态反馈与卡尔曼估计拼成 LQG。同屏列出三组极点：LQR 的、卡尔曼的、以及实际闭环的**八个特征值**（这里是 2+2 = 4 个）。
- **顿悟一（定理）**：闭环极点恰是 **LQR 极点 ∪ 卡尔曼极点**——两件事真的可以分开设计。这要能被读数**逐个数字**核对，不能只是画面上看着像。
- **顿悟二（代价，诚实收尾）**：状态反馈的 LQR 有保证的裕度（≥60° 相位裕度、增益裕度 [0.5, ∞)）；**一旦串上观测器，保证就没了**——Doyle 1978 的著名结论。工具要能实测出这件事：给出 LQR 状态反馈的裕度，再给出同一组权重下 LQG 的裕度，让后者可以被调到**任意小**。
- **tips**：最优不等于稳健。LQG 把两件事各自做到最优，却没有承诺拼起来还结实——这不是实现的缺陷，是定理的边界。
