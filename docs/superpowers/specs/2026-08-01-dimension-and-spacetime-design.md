## 0. 为什么是这两个

现有 51 个工具覆盖三角/几何/函数/线代/微积分/微分方程/力学/概率/离散/信号十个板块，**没有一个碰过"维度本身"或"时空几何"**。这两个主题共享一条暗线：*空间不是给定的容器，它的结构（有几个方向、方向之间怎么度量）本身就是被测量出来的东西*。所以它们成对推出，各自开一个新板块。

两个工具都用引擎的世界坐标，但**都不用历史采样流（`samples[]` 沿 +z 流出）**——它们的 z 轴另有所指：

| 工具 | x, y | z | 说明 |
|---|---|---|---|
| 维度与分形 | 对象所在平面 | **尺度轴** log(1/ε) / 迭代层号 n | 自相似"沿尺度堆叠"，与历史曲线沿时间流出同构 |
| 时空与光锥 | 两个空间维 | **ct 时间轴**（c = 1，光锥恰 45°） | 引擎的 z=时间约定在这里字面成立 |

这是有意的偏离：`pushSample()` 保持最小实现（只记 `t`），几何每帧由参数直接生成。§4.6 的"历史存当时真实值"不受影响——这两个工具没有需要保真的历史波形。

## 1. 工具 A · 维度的阶梯：从点到分形

- **id / file** `dimension-fractal-3d` / `outputs/dimension-fractal-3d.html`
- **板块** `dim`「维度与分形 / Dimension & Fractals」
- **accent** `cyan`
- **一句话** 把一个东西放大 *r* 倍，需要 *N* 份原件才填得满它 —— *d* = log *N* / log *r*。整数维和分形维是同一个公式的两段。

### 主线

$$N = r^{\,d} \iff d = \frac{\log N}{\log r}$$

点 *d*=0（放大后还是 1 个点）、线 *d*=1、方 *d*=2、立方 *d*=3、超立方 *d*=4；Cantor 集 *d*=log2/log3≈0.631、Koch 曲线 *d*=log4/log3≈1.262、Sierpinski 三角 *d*=log3/log2≈1.585。**全都落在同一族 log-log 直线上，斜率就是维数。** 分形不是"奇怪的东西"，只是斜率不是整数。

### PARAMS

| key | 标签 | 范围 | 说明 |
|---|---|---|---|
| `scaleR` | 放大倍数 *r* | 1.2 – 8，step .05 | 页签①；整数附近才画分割线 |
| `iter` | 迭代深度 *n* | 0 – 6，step 1 | 页签①②③的分形层数 |
| `logEps` | 盒子边长 log₂(1/ε) | 0 – 6.5，step .02 | 页签②；`map` 取 ε = 2^−logEps，须配 `invMap` |
| `dProbe` | 试探维数 *d* | 0 – 2.4，step .01 | 页签③ |
| `w4` | 4D 转角 *ξ* | 0 – 2π | 页签④，xw/yw 双旋转 |
| `wDist` | 4D 视距 | 2 – 6 | 页签④，w 方向透视强度 |

### 页签

#### ① 自相似维数阶梯 `ladder`
- **画**：x·y 平面上从左到右并排放一排对象——点、线段、正方形、立方体（厚度用 z）、以及三个分形（Cantor / Koch / Sierpinski）。滑 *r* 时每个对象被放大 *r* 倍并画出把它切回原尺寸所需的 *N* 份分割线。z 轴上同时画出 (log *r*, log *N*) 的散点轨迹。
- **曲线配色**（六处同源）：Cantor rose · Koch violet · Sierpinski emerald · 整数族 cyan(结构色) · log-log 直线族用各自对象色。
- **顿悟视角** `log-log 正视`（az≈0.001, el≈0.02）：七条直线扇形张开，斜率 0/0.63/1/1.26/1.58/2/3 一目了然，非整数斜率就夹在整数之间。
- **drive** `scaleR` linear pingpong 1.2→8，period 9。
- **tips**：维数不是"有几个坐标"，是"放大后要几份自己"。切到 log-log 正视，看 Koch 的斜率卡在 1 和 2 之间——它比线长，比面薄。

#### ② 盒计数 · 闵可夫斯基维数 `box`
- **画**：用边长 ε 的正方格覆盖当前分形（`iter` 决定层数），高亮被击中的盒子并计数 *N*(ε)。z 轴 = log(1/ε)：每个试过的 ε 在 z 上留下一个 (log(1/ε), log *N*) 点，连成散点；最小二乘拟合直线，**斜率即维数**。
- **对照组**：同时覆盖一个圆（violet，斜率→1）和一个实心圆盘（emerald，斜率→2），证明这套测法在已知情形下给出正确答案。
- **顿悟视角** `log-log 正视`：三条拟合线斜率 1 / 1.26 / 2；`覆盖俯视`（az=−π/2, el=1.52）看盒子贴着曲线。
- **drive** `logEps` linear pingpong 0→6.5，period 10。
- **tips**：维数可以**量**出来，不必事先知道。ε 缩小一半，圆的盒子数翻 1 倍、圆盘翻 4 倍、Koch 翻 2.4 倍——2^d 就是那个倍数。

#### ③ 豪斯多夫测度 `hausdorff`
- **画**：用**大小不一**的覆盖球（区间）盖住 Cantor 集，计算 Σ(diam)^*d*。滑 `dProbe`：
  - *d* < *d*_H → 和发散（画成冲出画面顶部并标 ∞）
  - *d* > *d*_H → 和塌向 0
  - *d* = *d*_H → 停在有限非零处
  z 轴 = 覆盖精度 δ 变细的过程：δ 越小越远，看到那条 Σ(diam)^d 关于 *d* 的曲线随 δ→0 越来越陡，极限就是在 *d*_H 处从 ∞ 到 0 的**跳变**。
- **豪斯多夫 vs 闵可夫斯基**：并排画同一集合的两种覆盖——闵可夫斯基强制**同尺寸**盒子，豪斯多夫允许**不同尺寸**并取下确界。所以 *d*_H ≤ *d*_M；对自相似集二者相等，这就是为什么页签②测出来的数和页签①算出来的数对得上。
- **顿悟视角** `跳变正视`：那条阶跃随 δ 变陡的族。
- **drive** `dProbe` linear pingpong 0→2.4，period 11。
- **tips**：维数的定义是"让测度既不爆炸也不消失的那个指数"。拖 *d* 越过 0.63，看 Cantor 集的测度从 ∞ 一步跌到 0——那个临界点就是它的维数。

#### ④ 超立方体 · 看见第四维 `tesseract`
- **画**：0→4 维的扫掠构造：点扫成线、线扫成方、方扫成立方、立方沿 *w* 扫成超立方（顶点 2ⁿ、棱 n·2ⁿ⁻¹）。4D 顶点先经 xw / yw 双旋转，再作 4D→3D 透视投影（`wDist`，w 越远越小），最后交给引擎相机做 3D→2D。
- **toggle**：逐级显示 0/1/2/3/4 维骨架；新增维度的那批棱用下一个语义色（rose→violet→emerald→orange）。
- **顿悟视角** `w 正对`（*ξ*=0 的正视）：小立方体同心套在大立方体里——它**不是**套着的，它只是在 *w* 上更远。这跟立方体画在纸上时"后面那个面看起来更小"是同一回事。旋转时内外立方体互相翻出来。
- **drive** `w4` circular loop 0→2π，period 12。
- **tips**：那个"立方体套立方体"的怪图不是四维的样子，是四维的**影子**。正如立方体在纸上的影子也是"方框套方框"。

## 2. 工具 B · 光锥：四维时空的因果结构

- **id / file** `spacetime-light-cone-3d` / `outputs/spacetime-light-cone-3d.html`
- **板块** `rel`「相对论与时空 / Relativity & Spacetime」
- **accent** `orange`
- **一句话** 取 *c* = 1，光锥就是 45° 的双锥。它把时空切成绝对未来、绝对过去与"别处"——而这把刀，换任何参考系都不动。

### 主线

不变间隔 $s^2 = (ct)^2 - x^2 - y^2$。它的符号定义因果（类时 / 类光 / 类空），它的等值面是双曲面，洛伦兹推动是保持它不变的**双曲旋转**。

坐标映射：x, y = 两个空间维，z = *ct*（*c* = 1，故光锥半顶角恰 45°，与引擎 `WAVE_LEN = 8` 的 z 跨度自然配合）。

### PARAMS

| key | 标签 | 范围 | 说明 |
|---|---|---|---|
| `flashT` | 闪光扩张时刻 *ct* | 0 – 4，step .02 | 页签① |
| `evR` | 事件空间距离 *r* | 0 – 4，step .02 | 页签② |
| `evT` | 事件时刻 *ct* | −4 – 4，step .02 | 页签② |
| `beta` | 推动速度 *β* = *v*/*c* | −0.95 – 0.95，step .005 | 页签①④⑤ |
| `tTurn` | 折返时刻 *ct*₁ | 0.5 – 3.5，step .02 | 页签③ 双生子 |
| `sInv` | 不变间隔 *s* | 0.4 – 3.5，step .02 | 页签⑤ |

### 页签

#### ① 闪光与锥的诞生 `birth`

**这一页回答"锥是哪来的"，必须排在最前面。** 没有它，45° 只是个约定。

- **画**：在 (x, y, *ct*) 里，从原点事件发出**一次闪光**。光以 *c* 各向同性向外走，所以在每个时刻 *ct* 它是一个半径 *r* = *ct* 的圆（amber）。滑 `flashT`，那个圆一边长大一边沿 +z 上升，**它扫过的曲面就是光锥**。当前圆用实线、已扫过的部分用锥面网格留痕。取 *c* = 1 ⇒ *r* = *ct* ⇒ 母线斜率恰 1 ⇒ 45°。
- **toggle「伽利略 / 爱因斯坦」**（对照组，这是本页的要害）：让一个观察者以 *β* 运动。
  - *伽利略*：速度叠加，光对他而言前后不等速 ⇒ 他画的"闪光圆"中心**跟着他跑**，锥**歪了**（violet 歪锥）。
  - *爱因斯坦*：实验说 *c* 对所有人一样 ⇒ 他的闪光圆中心仍在原点，锥**纹丝不动**（amber 正锥与 violet 重合）。
  - 让步的只能是"同时"：要让锥不动，等 *ct* 的那张切片就必须歪。**锥是不动点，同时面是让步的那一个** —— 这直接把页签④的剪切图预告出来。
- **推出度规**：既然 *r* = *ct*（即 (*ct*)² − *r*² = 0）对所有人都成立，那个量就是不变量的候选；把它推广到锥外锥内，就是 *s*² = (*ct*)² − *x*² − *y*²。读数区把这一步写出来。
- **顿悟视角** `x·ct 侧视`：圆的上升变成两条 45° 直线长出来；`俯视 x·y`：伽利略模式下圆心漂走，爱因斯坦模式下圆心钉死。
- **drive** `flashT` linear pingpong 0→4，period 8（闪光反复扫出锥面）。
- **tips**：锥不是画出来的，是**闪光扫出来的**。光速对谁都一样，所以这个锥对谁都一样——于是"同时"只好让位。切到俯视，开关伽利略/爱因斯坦，看圆心动还是不动。

#### ② 光锥与因果 `cone`
- **画**：以"此刻此地"为顶点的双锥——未来锥（+z）与过去锥（−z），锥面用 amber（度量注记色，因为光锥是**尺子**不是曲线）。测试事件 E 由 (`evR`, `evT`) 定位，其分类随位置改色：类时 rose、类光 amber、类空 violet。从原点到 E 画连线，锥内实线、锥外虚线。
- **读数**：`s² = (ct)² − r²`，符号 + 分类 + 一句人话（"你能影响它" / "它能影响你" / "彼此无法通信"）。
- **顿悟视角** `x·ct 侧视`（az=−π/2, el≈0.001）：教科书上那张标准 45° 双锥剖面图；`俯视 x·y`（az=−π/2, el=1.52）：看清"别处"是整个空间平面在此刻的样子。
- **drive** `evT` linear pingpong −4→4，period 9（事件穿过光锥，分类当场翻转）。
- **tips**：光锥不是光的轨迹，是**因果的边界**。让事件沿 *ct* 走一遍，看它从"绝对过去"经过"别处"进入"绝对未来"——在"别处"那段，它和你互相不存在。

#### ③ 世界线与固有时 `worldline`
- **画**：从事件 A 到事件 B 的三条世界线——静止者的直线（rose）、匀速折返的双生子（violet，折点由 `tTurn` 控制）、连续加速者（emerald，双曲线段）。每条线上按**固有时** τ 等间距打钟点，钟点疏密直接可见。所有世界线必须落在光锥内（|d*r*/d*ct*| < 1）——越界时线段变虚并提示。
- **读数**：三条的 Δτ 对比，以及 Δτ / Δt 比值。
- **顿悟视角** `x·ct 侧视`：钟点密度差一眼看到；直线上钟点最疏 = 固有时最长。
- **drive** `tTurn` linear pingpong 0.5→3.5，period 10。
- **tips**：闵可夫斯基几何里三角不等式**反过来**——两点之间，直的那条世界线**最长**。折返得越急，回来时你的钟走得越少。

#### ④ 洛伦兹推动与同时面 `boost`
- **画**：滑 *β*，画出运动观察者的 *ct*′ 轴（沿其世界线）与 *x*′ 轴（他的同时面），两轴向光锥**对称剪切**靠拢。取两个在 S 系同时的事件（violet 一对，同一 *ct*），显示它们在 S′ 系落在不同的同时面上。光锥**纹丝不动**。
- **顿悟视角** `x·ct 侧视`：剪切最清楚；`沿光锥看`（az/el 使锥退化成一条亮线）：无论 *β* 取多少，那条线不动。
- **drive** `beta` linear pingpong −0.9→0.9，period 10。
- **tips**："同时"不是宇宙的属性，是你**切**出来的一张面。拉动 *β*，两个同时的事件分开了先后——但光锥一动没动，所以因果没乱。

#### ⑤ 不变双曲线 `hyperbola`
- **画**：`s²` 的等值面——类时（*s*² > 0）是双叶双曲面，类空（*s*² < 0）是单叶双曲面，*s* = 0 恰是光锥本身。推动 *β* 时事件**沿双曲线滑动**而不离开它。同时画出这给 *x*′ / *ct*′ 轴带来的**刻度标定**：欧氏尺子在闵可夫斯基图上量不得。
- **驱动量用快度** *φ* = artanh *β* 而非 *β*（快度才是双曲"角度"，等速的 *φ* 给出等速的滑动）。
- **顿悟视角** `x·ct 侧视`：双曲线以光锥为渐近线；`立体`：双曲面的形状。
- **drive** `beta` linear pingpong −0.9→0.9，period 12（内部换算成 *φ*）。
- **tips**：推动就是**双曲旋转**。欧氏旋转让点沿圆走、保住半径；洛伦兹推动让事件沿双曲线走、保住 *s*。光锥是那条圆心退到无穷远的"圆"。

## 4. 与阶段 4（引擎加固）的关系

当前分支 `feat/engine-robustness-phase4` 正在做的事，是给 51 个工具的 `frame()` 加 `try/catch` + `finally` 里的 rAF。它的文档任务已合入（§8 自查清单已经把这条列为硬要求），代码任务尚未开始。

**决定**：两个新工具从当前 starter（`STARTER_VERSION 1.0.0`）复制，但**手写符合 §8 的 `frame()`**——整体 `try/catch`，`requestAnimationFrame(frame)` 放 `finally`。`engine-version` 如实记 `1.0.0`（这确实是它们复制自的 starter 版本）。

代价是阶段 4 的 `scripts/port_drive_engine.py` 在这两个文件上会**匹配失败**——这是想要的结果：脚本的约定是"命中失败即报错并跳过、打印跳过清单"，所以它们会以可见的方式出现在跳过名单里，而不是被静默漏掉。阶段 4 落地时把这两个文件的 `engine-version` 一并更新即可。

替代方案（先做完阶段 4 再建工具）会把这两个工具压后一整轮 51 文件扫描，收益只是省掉一次跳过清单的核对，不值得。

## 5. 验收

两个工具各自满足 §8 自查清单，重点：

- 曲线六处同源（图例点 / 曲线 / 投影虚线 / 头部光点 / 读数加粗值 / 公式标注）
- 每个页签有顿悟视角，`views` 首项为 `iso`
- 每个页签都有 `drive`（工具 A 四个 + 工具 B 五个，共 9 个页签，无静止页签，无需 `drive: null` 豁免）
- 每个场景声明 `params`，与实际读取的 state 键一致
- `logEps` 带 `map` 必须同时带 `invMap`；所有 `drive` 的 `[from, to]` 落在映射后的 `[min, max]` 内
- `frame()` 有 `try/catch`，rAF 在 `finally`
- 全部文案 `{zh, en}` 经 `t()`；`?lang=en` 直达、切换、记忆、`<html lang>` / `document.title` 跟随
- 语法门禁：`awk '/<script>/{f=1;next}/<\/script>/{f=0}f' FILE | node --check /dev/stdin`
- 版本三处落地：`tools.json` + HTML meta 两枚 + 头注释 changelog + 面板角标
