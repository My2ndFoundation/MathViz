# GA4 采集 + Cookie 同意设计

日期：2026-08-13
Measurement ID：`G-QJZ5Y8HQG9`
适用法域：UK GDPR + PECR（主体 DarkHorseOne 为英国公司，服务器在 eu-west-2 伦敦）

## 1. 目标

知道**哪些工具被用得多**，以及基本的访问量与来源。不做工具内的行为采集
（页签、停留、视角点击）。

## 2. 覆盖面：6 个导航页，97 个工具页一行不改

| 页面 | 数量 | 加 GA | 理由 |
|---|---|---|---|
| 画廊页 `index.html` ×3 | 3 | 是 | 落地页 |
| 导航壳 `app.html` ×3 | 3 | 是 | 工具都从这里打开 |
| 工具页 | 97 | **否** | 保住「单文件 · 零依赖 · `file://` 可开」——全仓当前 `<script src=` 出现 **0 次**，GA 会是第一个外部脚本 |
| `privacy.html` | 1 | **否** | 在解释追踪的那一页上追踪，法律上尴尬且无收益 |

「只加根目录的 `index.html` 和 `app.html`」不够：`chess/` 与 `cryptography/`
各有自己的画廊与壳，漏掉就是两个子项目的流量全部看不到。

## 3. 三个必须处理的结构事实

### 3.1 画廊页装在壳的 iframe 里 —— 会双计、会叠两个横幅

三个壳的 `srcFor(null)` 都返回 `index.html?lang=..&v=..`，即**画廊是被装进
iframe 的**。若 GA 同时在壳和画廊上无条件运行，打开壳会打两次 pageview，并且
两个同意横幅叠在一起。

而 `IN_SHELL`（`window.self !== window.top`）**只有根目录的 `index.html` 有**，
`chess/index.html` 与 `cryptography/index.html` 没有。

**因此注入的代码块自己判断是否在 iframe 里**，不依赖各页已有的变量。这既修好
了两个子项目，也避免了「三处各写一遍、其中一处忘了」。

### 3.2 GA 看不进 iframe —— 每个工具一次 pageview 必须由壳来发

壳用 `pushState` + `frame.contentWindow.location.replace()` 换工具，GA 的自动
pageview 只在壳加载时打一次：用户开 20 个工具，报表里仍是 1 次，且不知道是哪些。

三个壳都有 `go(id)`，它本来就知道当前工具。做法：

```js
gtag('config', 'G-QJZ5Y8HQG9', { send_page_view: false });
// 注入的代码块包装 window.go，在其后补发 page_view
```

**实现时改了做法（比本节初稿更好）**：初稿写的是「三个壳的 `go()` 里各手写一行」。
实际改为**包装 `window.go`**——`go` 是壳换工具的唯一漏斗，且是全局函数，包装它
让整件事 100% 由生成器产出，三个壳一行不改，也不需要为那三行单独设一道门。
代码块同时自己补发一次当前页的 pageview，覆盖住「壳初始加载时那次 `go()` 已经
发生过」的情况。闸门相应改为校验三个壳里 `function go(` 仍然存在——改名会让包装
**静默**失效。

**`send_page_view: false` 是必须的**：壳在初始加载时会调一次 `go()` 去恢复
`?tool=`，不关掉自动 pageview 就会把第一个工具计两次。

### 3.3 直接的工具 URL 绕过壳 —— 已知盲点，接受

侧栏的 ↗ 按钮是 `btnAlone.href = srcFor(curId)`，即**直接的工具页地址**，
新标签页打开，不经过 `app.html`。任何人分享该链接也一样。这些访问在本方案里
是不可见的。

这是「保住工具页零依赖」的代价，明确接受。要补的话，自建 Caddy 的访问日志能
看到全部请求且**不需要改任何页面**——但那是另一件事，本设计不做。

## 4. 同意先于加载，不用 Consent Mode

PECR 要求分析类 cookie **先取得同意再设置**。因此不采用「先加载 gtag、再标记
`analytics_storage: denied`」的 Consent Mode 写法，而是：**未同意就完全不注入
gtag 脚本**。更简单，也更经得起问。

同意状态存 `localStorage` 键 `mathviz-consent`（值 `granted` / `denied` /
不存在）。同源即共享，用户在三个子站之间只被问一次。

## 5. 横幅的合规要点

英国 ICO 明确要求，逐条对应到实现：

| 要求 | 实现 |
|---|---|
| 拒绝要和接受一样容易 | 两个按钮**同样的尺寸与视觉权重**，并排，不用「接受是实心、拒绝是小字链接」 |
| 不得预勾选 / 默认同意 | 无勾选框；未做选择时视同拒绝，不加载 GA |
| 可随时撤回，且和给出同意一样容易 | 页脚常驻「Cookie 设置」链接（就在版权那一行旁边），点开重新显示横幅 |
| 需说明采集了什么 | 横幅内链到 `privacy.html` |

关闭横幅（点 ✕ / 按 Esc）**等同拒绝**，不等同同意。

## 6. 语言：三个键、两种默认

| 页面 | `LANG_KEY` | 无 `?lang=` 且无存储时的默认 |
|---|---|---|
| 根目录 | `mathviz-lang` | 浏览器语言（`zh*` → zh，否则 en） |
| `chess/` | `chess-lang` | `en` |
| `cryptography/` | `cryptography-lang` | `en` |

注入的代码块**自包含地**复刻这套优先级（`?lang=` → `localStorage` → 默认），
不读页面的 `LANG` 变量——那个变量在壳里定义于 `.sb-foot` 之后，注入点若在其前
就读不到。生成器按路径决定写入哪个键与哪个默认值。

## 7. `privacy.html`

新建一页，遵循本仓一贯规则：单文件、零依赖、双语、带品牌 favicon 与版权署名。
内容至少覆盖：采集什么（GA4，含 IP 粗化后的地理、设备、访问的页面/工具）、
为什么、保留多久、法律依据（同意）、如何撤回、数据去了哪（Google，含美国传输）、
联系方式。

**不加 GA**（§2）。

## 8. 维护方式：扩展 `apply_footer.py`，不新增第三套

6 份相同代码仍是漂移风险（本仓在这上面栽过：62 条里 48 条版本号走偏；窄屏标题
的修法一季没回流到 67 个副本）。

在既有的 `scripts/apply_footer.py` 里加第二个生成区间 `GENERATED:ANALYTICS`，
只写给 `gallery` / `shell` 两类页面。复用已挂好的 pre-commit 与 CI 闸门，不新增
第三个脚本、第三道门。

壳里没有任何手写的采集代码（见 §3.2 的实现修正）。生成器**校验** `function go(`
在三个壳里存在，缺了就报红。

### 子项目的出站引用额度

同意横幅要链到根目录的 `privacy.html`，这让 `chess/` 与 `cryptography/` 的
`app.html` / `index.html` 各多一条 `../` 引用，`outbound_ref_check()` 当场报红
（已实测）。两个 `check.py` 的 `OUTBOUND_ALLOW` 从 1 提到 2。

**这条额度是有代价的**：它削弱的正是那道门守着的「子项目整个搬走后仍可用」——
`PARENT_HOME` 用「父级不存在就自己隐藏」化解了，隐私链接目前没有这层兜底，搬走
后会 404。接受的理由是 ICO 要求横幅必须能点到说明，而把同一份法律文本在三个子站
各复制一份是更糟的选择（正是本仓反复吃亏的漂移形态）。两处 `check.py` 的注释里
写明了这一点，免得后人以为额度可以随手再提。

## 9. 闸门与负向对照

`python3 scripts/apply_footer.py --check` 同时校验两个区间。

加闸门就要证明它会变红：

| 破坏 | 期望 |
|---|---|
| 删掉某个导航页的 `GENERATED:ANALYTICS` 区间 | 报红 |
| 改掉区间里的 Measurement ID | 报红 |
| 某个壳里 `function go(` 被改名 | 报红（包装会静默失效） |
| `privacy.html` 里仍有 `RETENTION_TBD` / `CONTACT_TBD` | 报红（法律文本不许带占位符上线） |
| 在工具页里出现 `GENERATED:ANALYTICS` | 报红（工具页不该有） |

## 10. 明确不做 / 已知盲点

- **不采集工具内行为**（§1）。
- **不在工具页加 GA**——保住零依赖（§2）。
- **直接的工具 URL 不可见**（§3.3），明确接受。
- **广告拦截器会屏蔽 GA**。对数学教学这类受众比例不低，所以 GA 的绝对数字
  只能当下限看。真要准确总量，用 Caddy 日志，本设计不做。
- **不做 Consent Mode**（§4）。
