## 0. 共同的约定（两个工具都适用）

### 0.1 只做单向推演

**从初始状态往后积分，不做反演、不做参数拟合、不做"回到过去"。** 这是刻意的：混沌的要害就是"前推容易、后推不可能"，工具的能力边界本身就是论点的一部分。

### 0.2 积分器与诚实的误差

混沌系统的长时积分必然失真，而且**误差也按指数放大**。两个工具都必须：

- **定步长子步进**：引擎每帧的 `dt` 被钳制在 `[0, 0.05]`，但直接拿它做一步积分对混沌系统是灾难。每帧内以固定步长 `h` 做 `ceil(dt/h)` 个子步（双摆 `h = 1/2000 s`，三体 `h = 1/1000` 无量纲时间单位），子步数设上限防止后台切回时卡死。
- **RK4**（双摆）/ **velocity-Verlet**（三体，辛格式，长时能量表现远好于 RK4）。
- **读数区常驻能量漂移** `|ΔE/E₀|`，三体另加角动量漂移。这不是瑕疵披露 —— **"你连模拟都算不准，正是因为它混沌"本身就是课程内容**，tips 要点出这一层。

### 0.3 种子绝不用 drive 驱动

初始条件是**种子**。§6「双语义迭代」那一条说得很清楚：给种子加 `drive` 会与「历史绝不重算」正面冲突。本设计的两个工具**一律不给种子加 `drive`**，改走 §8 的**出路①**：运动由引擎时钟直接驱动（积分自己在走），**每个场景留一行注释写明它靠什么在动**（出路④的痕迹要求）。

改动种子（滑杆或预设按钮）的语义是**重新播种**：清空轨迹、从新初值重新积分。这是显式的、用户发起的，不是每帧偷偷重算。

### 0.4 不许有"一次性演进后永久定格"

§8 的静止判据是「喂满 20 s 再推到 t ≈ 200 s，不重复帧 = 1 即定格」。两个系统的风险点不同：

- 双摆无阻尼，永远不会停 —— 天然合格。
- 三体**会**出现一体逃逸，画面变成一条无限后退的直线，实质定格。**必须处理**：当任一体超出半径 `R_esc`，或积分超过 `T_max`，场景**自动回到种子重新播种**，并在读数区留一行「第 n 次播种 · 上次因逃逸/超时结束」。这样它既永远在动，又诚实地说明发生了什么。

### 0.5 板块与配色

两个工具都进 `dyn`（已存在，无需改 CATS）。`dyn` 现有 `differential-equations-phase-space-3d`(orange) 与 `recurrence-iteration-dynamics-3d`(violet)，故：

- 混沌双摆 → accent `rose`
- 三体问题 → accent `emerald`

## 1. 工具 D · 混沌双摆：确定性的不可预测

- **id / file** `chaos-double-pendulum-3d` / `outputs/chaos-double-pendulum-3d.html`
- **accent** `rose` · **板块** `dyn`
- **一句话** 方程是确定的，初值差 10⁻⁶ 也照样分道扬镳 —— 混沌不是随机，是**确定性系统对初值的指数敏感**。

### 物理

双摆（无阻尼），拉格朗日量给出的标准运动方程，状态 `(θ₁, θ₂, ω₁, ω₂)`。取 `m₁ = m₂ = 1`、`L₁ = L₂ = 1`、`g = 9.81`。RK4，`h = 1/2000 s`。

坐标映射：**x, y = 摆所在的竖直平面，z = 时间轴**（历史曲线沿 +z 流出，正是引擎的原生用法）。

### PARAMS

| key | 标签 | 范围 | 说明 |
|---|---|---|---|
| `th1` | 初始角 *θ*₁ | 0 – π，step .005 | **种子**，改动即重新播种 |
| `th2` | 初始角 *θ*₂ | 0 – π，step .005 | **种子** |
| `logD0` | 初值偏差 log₁₀ *δ*₀ | −12 – −2，step .05 | 第二个摆的初值偏移；`map: v => 10^v`，**必须配 `invMap`** |
| `nEns` | 系综个数 *N* | 8 – 120，step 1 | 页签③ |
| `zScale` | 时间轴缩放 | 0.3 – 3，step .01 | 每秒对应多少世界单位 |
| `energy` | 系统能量 *E* | 见页签④ | 页签④按能量重新播种 |

### 页签

#### ① 双摆 · 两个几乎相同的开始 `twin`
- **画**：两套双摆同屏 —— 主摆（rose）与偏差摆（violet），初值只差 `logD0`（默认 10⁻⁶）。摆杆与摆锤画在 z = 0 的平面上，**下摆末端的轨迹沿 +z 流出**成为历史曲线。
- 一开始两条轨迹**完全重合成一条线**，看不出有两个系统；跑一阵后突然分岔，此后毫无关系。
- **读数**：当前分离 *δ*(*t*)（相空间四维欧氏距离）、*δ*/*δ*₀、以及「已经过去 *t* 秒 · 分离放大了 10^k 倍」。能量漂移常驻。
- **在动的机制**：积分器自己在推进，无 `drive`（出路①，场景内注释说明）。
- **顿悟视角** `θ₂·t 侧视`：两条曲线是一条线 —— 直到它们不是。
- **tips**：这不是随机。两个摆用的是同一个方程、同一台计算机，差别只在第 6 位小数。混沌的意思是：那第 6 位小数，迟早会变成第 1 位。

#### ② 分离的指数律 `lyapunov`
- **画**：把 log₁₀ *δ*(*t*) 对 *t* 作图（z 轴 = *t*）。混沌区间里它是一条**直线**，斜率即李雅普诺夫指数 *λ*（以 e 为底换算后标出）。饱和段（*δ* 长到系统尺度）要单独着色并标注「已饱和，此后不再有信息」。
- 同时画一族不同 `logD0` 的曲线（rose 深浅），它们**平行且等距** —— 初值精度每多一位小数，曲线只是整体下移一格，而**预测时限只增加 ln10/λ 秒**。这是本页的杀手锏。
- **读数**：拟合出的 *λ*、倍增时间 ln2/*λ*、以及「再多买 1 位小数 = 多 X.X 秒预测」。
- **顿悟视角** `log δ · t 正视`：一族平行直线。
- **tips**：想多预测一倍时间，初值精度要提高到 e^(λT) 倍。这就是为什么天气预报到不了两周 —— 不是算力不够，是**指数**不讲道理。

#### ③ 初值扇面 · 拉伸与折叠 `ensemble`
- **画**：在初值空间的一小段弧上撒 `nEns` 个初值（一条短短的 rose 线段），同步积分。看它被**拉伸**成长丝、被相空间的有界性**折叠**回来、反复几次后扒成一团絮。
- 这是混沌的**机制**本身：拉伸产生敏感依赖，折叠保证有界，两者共存就是混沌。
- **读数**：初始弧长、当前丝长、折叠次数（用丝的转向计数近似）、丝长/初始弧长。
- **顿悟视角** `θ₁·θ₂ 正视`（相平面）：看丝的拉伸与折叠；`立体`：丝沿时间轴的演化。
- **tips**：混沌不是"乱"，是两件很规矩的事同时发生：**拉伸**让邻居分开，**折叠**让它们回不到无穷远。只有拉伸是发散，只有折叠是周期，两个一起才是混沌。

#### ④ 从可积到混沌 `transition`
- **画**：庞加莱截面（取 *θ*₁ = 0 且 *ω*₁ > 0 的穿越点，画在 (*θ*₂, *ω*₂) 平面上）。低能量时是一圈圈干净的**定线**（KAM 环面），能量升高时环面从共振处开始碎裂，最后海洋弥漫开。
- `energy` 滑杆按能量重新播种，同一能量下撒若干条轨道各自打点，用不同色（rose → violet → emerald → orange）。
- **读数**：当前能量、相对翻越能量的比值、规则区/混沌区的点数占比。
- **顿悟视角** `截面正视`：环面碎裂的全过程。
- **tips**：混沌不是开关，是**渗透**。能量一点点升高，规则的环面先在共振处裂开一串小岛，混沌的海从缝里渗进来，最后连成一片。

## 2. 工具 E · 三体问题：一条四维曲线的三个影子

- **id / file** `three-body-problem-3d` / `outputs/three-body-problem-3d.html`
- **accent** `emerald` · **板块** `dyn`
- **一句话** 三个质点、一条牛顿定律，没有解析解。真实运动在三维空间里，而我们只能一次看它的一个影子。

### 物理

牛顿引力，`G = 1`，三体质量可调。**软化参数** `ε`（力 = *Gm*₁*m*₂ **r** / (*r*² + *ε*²)^{3/2}）避免近距离遭遇时数值爆炸 —— 必须在 tips 或读数里说明这是数值处理而非物理。velocity-Verlet，`h = 1/1000`。

**这个工具的位置是真三维的**（ℝ³），这正是它与双摆工具的分别。

### 投影：本工具的核心机制

真实状态是 ℝ³ 里的三条轨迹；加上时间，本体是 **(x, y, z, t) 里的一条四维曲线**。引擎只有三根世界轴，所以每次只能看它的一个三维影子。四种喂法，由页签②的一个 toggle 组切换：

| 世界 x | 世界 y | 世界 z | 得到 |
|---|---|---|---|
| *x* | *y* | *z* | **纯空间**：真实轨道，无时间 |
| *x* | *y* | *t* | 第一张时间辫 |
| *y* | *z* | *t* | 第二张时间辫 |
| *x* | *z* | *t* | 第三张时间辫 |

**纯空间视图是必须的** —— 只有三张时间辫的话，永远看不到真实轨道长什么样，会被影子绑架。**时间轴缩放滑杆也是必须的** —— 空间单位与时间单位挂在正交轴上，比例是人为的，不给缩放则积分久了辫子压成一根针。

### PARAMS

| key | 标签 | 范围 | 说明 |
|---|---|---|---|
| `preset` | （用预设按钮而非滑杆） | — | 图8编舞 / 拉格朗日三角 / 随机三维初值 |
| `tilt` | 轨道平面倾角 | 0 – π/2，step .005 | 把平面解转到一般姿态，三张影子才会各不相同 |
| `zScale` | 时间轴缩放 | 0.2 – 4，step .01 | 每单位时间对应多少世界单位 |
| `trail` | 拖尾长度 | 1 – 40，step .5 | 无量纲时间 |
| `logD0` | 扰动 log₁₀ *δ*₀ | −10 – −1，step .05 | 页签③④；`map`/`invMap` 成对 |
| `soften` | 软化参数 *ε* | 0.005 – 0.15，step .001 | 数值处理，读数里注明 |

### 页签

#### ① 空间中的真实运动 `orbit`
- **画**：世界坐标 = (*x*, *y*, *z*)，三体各自语义色（rose / violet / emerald），带拖尾与头部光点；质心用 cyan 小点钉住（动量守恒 ⇒ 质心匀速，可选择在质心系里画）。
- **读数**：三体间距、总能量与其漂移、总角动量与其漂移、最近接近距离。
- **在动的机制**：积分器推进，无 `drive`（出路①，注释说明）。
- **顿悟视角** `立体` + 两个正交视角。
- **tips**：这是它**真正**在做的事。下一页你会看到，只要换一个方向去看，同一段运动可以像三段完全不同的运动。

#### ② 三重投影 · 一条四维曲线的三个影子 `shadows`
- **画**：上表四种喂法，toggle 切换。切换时相机做 tween（引擎已有 750ms easeInOutCubic），让"同一段运动换个投影"这件事被看见而不是跳变。
- **标定用法（重要）**：先用**图 8 编舞**（一条你事先知道形状的干净闭合曲线），把 `tilt` 拧到一般姿态 —— 三张影子会长得完全不一样。**先在已知答案上验证"影子会骗人"，再切到混沌初值**，说服力完全不同。
- **读数**：当前投影、被丢掉的是哪个坐标、以及该投影下"看起来的"最近接近距离 vs **真实**三维最近接近距离（两者常常差很多，这是影子欺骗性的量化证据）。
- **顿悟视角** 四种投影各配一个预设；首项仍是 `iso`。
- **tips**：三张辫子不是三个系统，是同一条四维曲线 (*x*, *y*, *z*, *t*) 的三个三维影子。哪一张都不是真相 —— 就像立方体在纸上的影子是个方框套方框。

#### ③ 图 8 编舞 · 稳定解是刀锋 `choreo`
- **画**：Chenciner–Montgomery 的图 8 编舞（三体等质量、共用一条 8 字轨道，互差 1/3 周期）—— 一个**稳定的周期解**。跑很多周期都不散。
- 然后按 `logD0` 给一体一个微扰，同屏并排（原解 emerald，扰动解 rose）：起初完全重合，若干周期后离开轨道、结构瓦解。
- **读数**：周期数、与原轨道的偏离、能量漂移；瓦解时标注「第 n 周期失去编舞」。
- **顿悟视角** `轨道正视`：干净的 8 字；`并排对比`。
- **tips**：三体不是**总是**混乱，是**几乎总是**。图 8 这样的精确解存在，但它像刀锋上的平衡 —— 推一下 10⁻⁸，几十个周期后就找不回来了。

#### ④ 分道 · 逃逸 · 守恒量 `divergence`
- **画**：两套三体，初值差 `logD0`，画 log *δ*(*t*)（同工具 D 页签②的读法，但这里的 *δ* 是 18 维相空间距离）。同时把**近距离遭遇**标出来 —— 分离的跳变几乎总是发生在一次近距离遭遇之后，因为那是放大器。
- 一体逃逸时按 §0.4 自动重新播种并计数。
- **读数**：*λ*、能量与角动量漂移、遭遇次数、逃逸次数、「第 n 次播种」。
- **顿悟视角** `log δ · t 正视`。
- **tips**：三体的混沌有个具体的放大器 —— **近距离遭遇**。两体擦身而过时，出射方向对入射参数极度敏感，一次遭遇就能把 10⁻¹⁰ 的差别放大好几个数量级。看分离曲线的每一次跳变，下面都对应一次遭遇。

## 2.5 后续阶段：save / load / replay（已确认，本期不做）

**决定（2026-08-02）**：两个工具先按本规格落地并各自开 PR；record/replay 作为**独立的下一期**，文档先行，做成**引擎能力**而非两份手写实现。

理由：通用部分（序列化、下载 / 上传、回放时钟、面板控件、版本与兼容性校验）两个工具完全一样，只有三个钩子是各自的 —— `captureState()` / `restoreState(s)` / `stepPhysics(h)`。这个仓库的引擎之所以长成 51 份互有差异的副本，正是因为同一件事被手写了很多遍；让两个并行的 agent 各写一遍，格式与 UI 几乎必然对不齐，日后抽取反而更贵。做进 starter 后，同类工具（`recurrence-iteration-dynamics-3d`、`optimization-convexity-gradient-descent-3d`、`markov-chains-stationary-distribution-3d`）都能继承。

下一期要覆盖的要点，记在这里以免丢失：

1. **两种存档并存。** 系统是确定性的，初值 + 积分参数就唯一决定整条演化，所以**种子存档**只要几百字节；但用户要的是能逐帧忠实回放的**轨迹存档**（抽样后几百 KB ~ 几 MB）。默认存轨迹，种子存档作为轻量选项。
2. **浮点复现性不能假设。** ECMAScript 不保证 `Math.sin` / `Math.pow` 等超越函数跨实现逐位相同，而对混沌系统 1 ULP 的差别会指数放大。因此「从种子在别人机器上重跑」**可能对不上**，这不是缺陷而是事实，必须在 UI 里讲明白。
3. **把这一点变成功能。** 存档同时带种子与轨迹；加载时用种子重新积分，与记录的轨迹**逐点比对并画出分离曲线**。复现不了的时候，工具就在自己身上演示了自己的论点 —— 这是课程内容，不是噱头。
4. **replay 态必须是一等状态**，不是"暂停 + 手动拖时间"：进入后禁用种子滑杆、面板显示存档来源与时间轴、可暂停 / 逐帧 / 变速，退出即回到实时积分。
5. **格式要自带版本与工具 id**，加载不匹配的存档必须明确拒绝并说明原因，不做兼容性猜测。
6. **落地形态**：先改 `design-system/math-viz-design-system.md`（仓库明文纪律：先改文档再改代码），再改 starter，最后把两个工具接上钩子并 bump 到 1.1.0。

## 4. 验收

各自满足 §8 自查清单，重点：

- 曲线六处同源；每个页签有顿悟视角，`views` 首项为 `iso`
- **没有静止页签**：每个场景都靠积分器在动，**且每个场景内留一行注释写明这一点**（出路①＋出路④的痕迹要求）；三体必须实现 §0.4 的逃逸/超时重新播种，否则会被判定为"一次性演进后永久定格"
- **不给任何种子参数加 `drive`**（§6 双语义迭代冲突）
- 每个场景声明 `params`，与实际读取的 state 键一致
- 带 `map` 的参数（`logD0`、`logEps` 类）必须成对提供 `invMap`
- `frame()` 有整体 `try/catch`，`requestAnimationFrame` 在 `finally`
- 全部文案 `{zh, en}` 经 `t()`；`?lang=en` 直达、切换、记忆、`<html lang>` / `document.title` 跟随
- 语法门禁：`awk '/<script>/{f=1;next}/<\/script>/{f=0}f' FILE | node --check /dev/stdin`
- 版本三处落地：`tools.json` + HTML meta 两枚 + 头注释 changelog + 面板角标
- **性能**：最坏情况（三体页签④双系统 + 长拖尾 / 双摆页签③ N = 120）单帧 `draw()` 不超过 8 ms；子步数有上限
- **数值自检（必须实测并写进报告）**：
  - 双摆小角度极限下的两个简正频率与解析值相符（*θ* < 0.01 rad 时）
  - 双摆无阻尼积分 60 s 后 `|ΔE/E₀| < 10⁻⁶`
