## 0. 这个工具补的是哪一块

`spacetime-light-cone-3d` 讲的是**光锥的几何**：锥怎么被闪光扫出来、锥怎么切分因果、推动怎么剪切同时面。它的起点已经是「c 不变」这条公理。

本工具讲的是**公理之前的那一段**：牛顿的平直时空长什么样、它在哪里裂开、以及那个著名的「时间前面加个负号」到底是怎么被逼出来的。终点才是闵可夫斯基时空，正好接上前作的起点。

一句话主线：

> **牛顿时空和闵可夫斯基时空的差别只有一条 —— 有没有一个不变的速度。**

有绝对时间 ⇒ 伽利略变换是剪切、c = ∞；有不变速度 c ⇒ 度规必须带一个负号、洛伦兹变换是双曲旋转。而 *v* ≪ *c* 时两者数值上无法区分 —— 这就是牛顿力学统治两百年的原因，也是「相对论效应何时开始接管」这个问题的答案所在。

- **id / file** `newton-to-minkowski-3d` / `outputs/newton-to-minkowski-3d.html`
- **板块** `rel`（已存在，无需新增 CATS）
- **accent** `violet`
- **坐标** 与前作一致：x, y = 两个空间维，z = *ct*，*c* = 1

### 与 `spacetime-light-cone-3d` 的边界

前作的第①页签 `birth`（闪光生锥）也有一个伽利略/爱因斯坦对照，但问的问题不同：那里问**闪光圆的圆心动不动**，这里问**追光者测到的光速是多少、以及两套速度叠加律何时分家**。实现时不要把 `birth` 的画面搬过来。

## 2. 页签

### ① 牛顿的平直时空 `newton`

- **画**：(x, y, *ct*) 里的**分层蛋糕** —— 绝对时间把时空切成一叠水平的同时面（cyan，结构色），每一层是整个空间的一个瞬间，所有观察者共用这一叠切片。放三条世界线：静止者（rose）、匀速者（violet）、另一个方向的匀速者（emerald）。
- **伽利略变换就是剪切**：滑 `beta`，世界线整体倾斜，**同时面纹丝不动**。这是牛顿时空的全部结构 —— 时间间隔与「同一时刻的空间距离」是两个互不相干的不变量，没有任何东西把空间和时间联系起来。
- **读数**：Δ*t* 在所有 *β* 下恒定；同一时刻两点的 Δ*r* 也恒定；「不变速度：无（c = ∞）」。
- **drive** `beta` linear pingpong −0.9→0.9，period 9。
- **顿悟视角** `x·ct 侧视`：世界线来回歪，水平的同时面一动不动。
- **tips**：牛顿时空不是"三维空间加一根时间轴"那么随便 —— 它是一叠**绝对的**同时面。伽利略变换只敢推倒世界线，不敢碰这叠切片。看 β 怎么变，水平线就是不动。

### ② 速度叠加的裂缝 `crack`

- **画**：一束光（amber）+ 一个以 *β* 运动的观察者。
  - 伽利略预言：他测到的光速是 1 − *β*，随他而变（violet 斜线）。
  - 实验（迈克耳孙–莫雷）与爱因斯坦：永远是 1（amber 水平线）。
  把「测到的光速」作为 *β* 的函数画成一条曲线 —— **那条水平线就是全部的输入**，整个相对论都是从它推出来的。
- **第二层**：速度叠加律的分岔。伽利略 *u* + *β*（violet 直线）vs 相对论 (*u* + *β*)/(1 + *uβ*)（rose 曲线），由 `uB` 给出 *u*。两条在小速度处重合到看不出差别，接近 1 时分道扬镳，且相对论那条**永远不越过 1**。
- **读数**：两套叠加结果、相对差；并标出「*u* = *β* = 0.9 时伽利略给 1.8，相对论给 0.994」。
- **drive** `beta` linear pingpong 0→0.95，period 9。
- **顿悟视角** `u·结果 正视`：两条叠加曲线的分岔；`x·ct 侧视`：光与追光者的世界线。
- **tips**：牛顿力学没有错在"速度不能相加"，错在**默认了没有上限**。相对论的叠加律在低速处和它差不到一个测量精度，却永远撞不破 1。

### ③ 符号的诞生 `signature` —— 本工具的核心页签

**这一页回答用户点名的问题：时间前面那个负号是怎么来的。**

- **设定**：时空的不变量取待定二次型

  *Q*<sub>ε</sub> = (*ct*)² + *ε*(*x*² + *y*²)

  `sig` 滑块直接控制 *ε*。场景里**始终画着一条光的世界线** *r* = *ct*（amber 母线），读数实时显示 *Q*<sub>ε</sub> 在它上面的值 = (1 + *ε*)(*ct*)²。
- **要求只有一条**：光的世界线必须落在 *Q* = 0 上（因为 *c* 对所有人相同，这个集合必须与观察者无关）。代入即得 (1 + *ε*) = 0 ⇒ ***ε* = −1**。**没有别的选择** —— 推导过程就是画面本身。
- **滑 ε 从 +1 扫到 −1，三种几何依次显形**：

  | *ε* | 等值面 *Q* = ±\|*Q*\| | 零集 *Q* = 0 | 是什么 |
  |---|---|---|---|
  | **+1** | 球面 | **一个点**（原点） | 四维欧氏。没有锥；而且旋转能把未来转成过去，因果崩溃 |
  | **0** | 一对水平平面 *ct* = ±√\|*Q*\| | **整个 *ct* = 0 平面** | 退化 ⇒ **牛顿的绝对同时**（正是页签①那叠切片） |
  | **−1** | 双曲面 | **45° 双锥** | 闵可夫斯基 ⇒ **光锥在这里诞生** |

  零方向的维数因此从 0 维的点 → 2 维的平面 → 2 维的锥面。锥是**同号做不到、零号也做不到**的那个东西。
- **toggle「*ict* 视角」**：还原闵可夫斯基当年真正的那一笔 —— 令 *x*₄ = *ict*，形式上 *Q* = *x*² + *y*² + *x*₄² 又变回欧氏平方和，减号藏进了虚数里。同时演示「转一个虚角度」：cos(*i*φ) = cosh φ、sin(*i*φ) = *i* sinh φ，欧氏旋转就地变成双曲旋转 —— 这条直接接上页签④。
- **读数**：*ε*、当前几何名（欧氏 / 伽利略退化 / 闵可夫斯基）、*Q*<sub>ε</sub> 在光世界线上的值、零集的维数与形状。
- **drive** `sig` linear pingpong 1 → −1，period 10（让符号自己扫过去）。
- **顿悟视角** `x·ct 侧视`：等值面剖面从圆 → 一对水平线 → 双曲线，零集从**一个点** → **一条水平线** → **45° 交叉线**；`立体` 看球 → 平面 → 锥的形变。
- **tips**：时间前面那个减号不是约定，是被逼出来的。二次型要在**一整个锥**上取零，两项的符号就必须相反 —— 同号只能零在一个点上，零号则退化成牛顿的绝对同时。拖 *ε* 走一遍这三种情形。

### ④ 重建：剪切 → 双曲旋转 `rebuild`

- **画**：**三种"旋转"并排**，同一个参数下各自保住什么。

  | 变换 | 保住的量 | 轨道形状 |
  |---|---|---|
  | 欧氏旋转 | *x*² + *y*² | 圆（emerald） |
  | 伽利略剪切 | *t* | 水平线族（violet） |
  | 洛伦兹推动 | (*ct*)² − *x*² | 双曲线（rose） |

  同一个 *β* 下把伽利略与洛伦兹**叠在一起**：伽利略把 *ct* 轴推倒而 *x* 轴不动；洛伦兹把 *ct*′ 与 *x*′ **对称地**向光锥挤。差别在低 *β* 时几乎看不出来，这一点要能直接读出来。
- **读数**：两种变换下同一事件的像、二者之差、以及该差值相对于坐标本身的比例。
- **drive** `beta` linear pingpong −0.9→0.9，period 10。
- **顿悟视角** `x·ct 侧视`：三种轨道（圆 / 水平线 / 双曲线）同框。
- **tips**：换一个参考系是"转一下"，问题只是**沿什么轨道转**。保住圆的是欧氏旋转，保住水平线的是牛顿，保住双曲线的才是我们这个宇宙。

### ⑤ γ 什么时候接管 `gamma`

**这一页回答用户的另一半问题：速度多大时相对论效应开始占主导。**

- **画**：*γ*(*β*) = 1/√(1 − *β*²)，横轴用对数（`logBeta` 扫 10⁻⁸ → 0.999）。在曲线上钉出真实世界的位置：步行 ~10⁻⁸、客机 ~10⁻⁶、近地卫星 ~2.6×10⁻⁵、GPS 卫星、LHC 质子 ~0.999999991。
- **并列三个效应随 *β* 的偏离**（各自语义色）：时间膨胀 Δ*t*′/Δ*t*（rose）、长度收缩（violet）、动能 (*γ*−1)*mc*² 相对于 ½*mv*² 的偏差（emerald）。
- **顿悟**：*β* < 0.1 时 *γ* − 1 < 0.5%，牛顿力学的误差小于当时的测量精度 —— **这就是它对了两百年的原因**；*β* > 0.87 时 *γ* > 2，相对论完全接管。这两条阈值要在画面上标出来。
- **读数**：当前 *β*、*γ*、*γ*−1、三个效应的数值，以及一句「牛顿在这里还差多少」。
- **drive** `logBeta` linear pingpong 10⁻⁸ → 0.999079，period 12。
- **顿悟视角** `log-log 侧视`：低速端 *γ* − 1 ≈ *β*²/2 的渐近直线与 *β* → 1 的发散同框。
- **tips**：牛顿力学不是错的，是**低速极限**。γ−1 在 β = 0.1 处才 0.5%，在 β = 0.9 处已经是 130% —— 相对论不是替换了牛顿，是在牛顿看不见的那一端接管了。
