## 0. 主线与共同约定

### 0.1 一根杆子贯穿到底

**被控对象自始至终是倒立摆。** 工具 A、B 用力矩驱动的单摆（2 个状态 θ、ω），工具 B 的压轴页与工具 C 换成小车-摆 / 火箭 —— 但结构完全一样：**推力/力矩作用在下面，重心在上面，任何角度偏差都自己长大**。

倒立摆的线性化模型是整条线的锚：

    θ̈ = (g/L)·θ + u/(mL²)   ⇒   开环极点 s = ±√(g/L)

**右半平面那个正极点，就是「必倒」的数学。** 三个工具的读数区都要能显示它，让抽象量始终挂在看得见的物理上。

### 0.2 顿悟主线（入门 → 精通）

1. 反馈让你**不必知道精确模型**
2. **P / I / D = 现在 / 过去 / 未来**
3. 稳定性不是物体的属性，是**回路**的属性
4. **失稳的根源是相位，不是幅值** —— 力不是太大，是来得太晚
5. **内模原理**：要消掉什么，回路里就得装什么的模型
6. **水床效应**：灵敏度守恒，控制没有免费午餐
7. **必要多样性**：作动自由度少于被控自由度时，只能交易，不能全要
8. **被控对象会变**：你调的参数只在某一段是对的

### 0.3 共同技术约定

- **定步长子步进**：控制系统的教学价值高度依赖数值可信，绝不拿引擎每帧 `dt` 直接积一步。物理用 RK4，`h = 1/2000 s`，每帧 `ceil(dt/h)` 个子步并设上限。
- **控制器是离散的**：按采样率 `fs` 以零阶保持更新，**这是刻意的** —— 采样带来的纯延迟是工具 A③ 与工具 C 的核心教学点，连续控制器会把它藏起来。
- **饱和与限速要显式画出来**：作动量到限幅时必须在画面上有可见标记，否则「为什么高增益反而更糟」讲不清。
- **每个页签都靠积分器自走**（§8 出路①），场景内留注释；种子参数一律不加 `drive`（§6 双语义迭代）。
- **能量/裕度类读数常驻**，与混沌两工具同一条诚实原则。

### 0.4 板块与配色

新增 `ctrl`「控制论与反馈 / Cybernetics & Feedback」，`CATS` 插在 `dyn` 之后（两处同序）。

- 工具 A 反馈与 PID → accent `cyan`
- 工具 B 深层结构 → accent `violet`
- 工具 C 火箭 → accent `orange`

## 1. 工具 A · 让倒立摆站起来（入门）

`ctrl-feedback-pid-3d` / accent `cyan`

### ① 开环 vs 闭环 `loop`
两个相同的摆，同一阵扰动。开环（violet）倒下，闭环（rose）拉回。θ(t) 沿 +z 流出。
**「偷偷改摆长」开关**：运行中把 L 改掉 30%，开环立刻散架，闭环只是轻微抖一下就稳住 —— 这是「不必知道精确模型」的实证，不是口号。
读数：开环极点 +√(g/L)（右半平面）vs 闭环极点。
顿悟视角 `θ·t 侧视`。tips：开环那根不是「没控制」，是「控制了但不看结果」。

### ② P / I / D = 现在 / 过去 / 未来 `pid`
**核心页。** 三项贡献分色沿时间轴流出并叠成 u：`u_P` rose、`u_I` violet、`u_D` emerald、合成 u 用 cyan。
逐项开关 + 常值扰动开关 + 测量噪声开关：
- 只有 P：有常值扰动时**稳态误差不为零**，且欠阻尼
- 加 I：稳态误差归零，但超调变大（相位滞后的代价）
- 加 D：阻尼上来；**打开噪声，D 项当场被撕碎**
读数：三项实时占比。顿悟视角 `三项 u·t 侧视`。
tips：P 看现在、I 看过去、D 看未来。误差的三个时态，一个控制器全占了。

### ③ 力不是太大，是来得太晚 `phase`
`Kp` 从过阻尼推到发散；**延迟滑杆**（0–80 ms）一拉，临界 Kp 骤降。
画 θ(t) 与 u(t) 的相位差：延迟让纠正到达时误差已经反号，**纠正于是变成了驱动**。
读数：当前相位裕度、临界 Kp 随延迟的下降。
tips：失稳的根源是相位，不是幅值。

### ④ 测不到的量 `observer`
三条 ω：真实（灰）、差分求导（orange，被噪声撕碎）、观测器估计（emerald，干净且跟得上）。
顿悟：**不要微分噪声，要用模型去估计**。这也解释了实际中 D 项为何必须滤波。
tips：D 项的坏名声一大半来自「直接微分测量」。

## 2. 工具 B · 从根轨迹到守恒律（精通）

`ctrl-locus-limits-3d` / accent `violet`

### ① 根轨迹：极点在增益里迁移 `locus`
**复平面在 x·y，增益 K 沿 z 轴。** 闭环极点随 K 划出三维曲线束；开环极点 ±√(g/L) 是 K = 0 的起点。
倒立摆是反的：**K 太小才不稳** —— 曲线从右半平面出发，穿过虚轴进入左半平面。
同屏小窗给出当前 K 的 θ(t) 响应，与极点位置一一对应。
顿悟视角 `沿增益轴俯视` = 教科书那张标准根轨迹图；转过来才看见它是三维曲线束。
tips：极点实部是衰减率、虚部是振荡频率。你调的不是手感，是这两个数。

### ② 内模原理 `imp`
常值扰动：P+D 留下稳态误差，加 I（**常值信号的模型**）归零。
正弦扰动（摆座周期性晃动）：P+I+D 也压不干净；在回路里加该频率的**谐振器**，误差谱上那根尖峰被「打洞」打掉。
顿悟：**要消掉什么，回路里就得装什么的模型。** I 项不是玄学，它是常值的模型。
tips：控制器必须包含它要对抗的那个世界的模型。

### ③ 水床效应：灵敏度是守恒的 `waterbed`
沿频率轴画 ln|S(jω)|，**用填色显示它的面积**，实时给出数值。
调任何参数：某频段压下去，别处必然鼓起来，面积不变。
倒立摆有一个右半平面极点 p = +√(g/L)，故 ∫₀^∞ ln|S| dω = **π·p > 0** —— 不是零，是一个正的下限。
顿悟：**它的不稳定，给你的水床压了一个不可讨价还价的代价。**
顿悟视角 `ln|S| · ω 正视`。

### ④ 必要多样性：一只手，两件事 `variety`
换成 **cart-pole**：一个作动器（小车推力），两个要管的量（摆角 + 小车位置）。
只稳角度 → 小车匀速漂走；要管住位置 → 必须**先把摆推向反方向**（非最小相位）。
顿悟：**作动自由度少于被控自由度时，只能交易，不能全要。** Ashby 的必要多样性在这里不是哲学，是你亲眼看见小车漂走。
tips：欠驱动不是工程缺陷，是变量数的算术。

## 3. 工具 C · 火箭：会自己变的倒立摆（沙盒）

`ctrl-rocket-tvc-3d` / accent `orange`

**火箭就是倒立摆** —— 推力矢量接在下面，重心在上面。它多出来的是：被控对象在飞行中**自己变**，扰动通道**变多**，作动器**有限**。

### 3.1 模型（二维竖直平面，诚实优先）

状态 `(x, z, vx, vz, θ, ω)`。质量 `m(t)` 随燃料线性下降，转动惯量 `J(t)`，**重心位置 `c(t)` 随燃料迁移**（方向与幅度由滑杆给，不冒充某型号真实数据 —— 注释里写明这是教学参数）。

- 推力 `T` 经喷管摆角 `δ` 作用：力矩 `= T·sin δ·ℓ(t)`，`ℓ(t)` 是喷管到重心的力臂
- **等效控制增益 `T·ℓ(t)/J(t)` 一路漂移** —— 这是本工具的心脏
- 气动力作用在压心，压心在重心之下时**加剧不稳定**
- 风：常值 + 阵风（随机种子可设，**存进存档才能复现**）
- 作动器：`|δ| ≤ δmax`，且**摆动速率受限**
- 控制器：姿态 PID，按 `fs` 零阶保持离散更新

### 3.2 页签

#### ① 飞行 `flight`
三维姿态与轨迹，喷管摆角可见，限幅时喷管变色。风用箭头场表示。
读数：高度、姿态角、燃料、**当前等效增益 T·ℓ/J**、各项裕度。

#### ② 姿态与控制量 `signals`
θ(t)、δ_cmd(t)、δ_actual(t) 沿时间轴。**采样阶梯要画出来**（零阶保持的台阶），限幅段与限速段分别着色。
顿悟：把 `fs` 调低，台阶变粗，相位裕度被吃掉 —— **工具 A③ 的教训，这次是你亲手撞的墙**。

#### ③ 裕度仪表盘 `margins`
相位裕度、增益裕度、作动余量（离饱和还有多远）**随时间/燃料变化**的三条曲线。
顿悟：**它们不是常数。** 飞到后段，你起飞时调好的裕度可能已经耗光。

#### ④ 增益调度 `schedule`
同一阵风、同一组初值，**定增益 vs 随 T·ℓ/J 调度的增益**并排飞。
顿悟：**你调的那组参数只在飞行的某一段是对的** —— 这就是真实火箭做增益调度的原因。

### 3.3 「游戏」怎么做而不破坏设计系统

不引入新的交互范式：参数照常用滑杆，**`重置`（R）就是「再发射一次」**。区别只在读数区多一条**结局与诊断**：

    结局：翻滚失控 · t = 23.4 s
    诊断：采样率 12 Hz ⇒ 零阶保持等效延迟 42 ms ⇒ 相位裕度在 t = 19 s 归零

**每一次坠毁都必须可诊断，不能是随机翻车 —— 那才是教学载荷。** 诊断按以下优先级判定并给出首要死因：

| 死因 | 判据 |
|---|---|
| 采样过慢 | 相位裕度归零，且零阶保持延迟是裕度损失的主因 |
| 增益过高 + 饱和 | 出现极限环，且 δ 长期贴在 δmax |
| 增益调度缺失 | 起飞时裕度充足，随 T·ℓ/J 漂移在后段归零 |
| 积分饱和 | 持续风下 I 项发散、退饱和滞后导致过冲 |
| 作动器太慢 | 速率限幅是限制项，δ_cmd 与 δ_actual 长期分离 |

**接入 §11 演算记录与回放**：一次发射 = 一轮。风的随机种子与全部参数进 `seed()`，于是**一次漂亮的（或惨烈的）飞行可以存下来、发给别人、逐帧复看**。这正是这个功能的用武之地。

## 4. 注册与验收

各自满足 §8 自查清单，重点：

- 曲线六处同源；每页有顿悟视角，`views` 首项 `iso`
- 12 个页签全部靠积分器自走，场景内留注释；**无任何种子加 `drive`**
- 带 `map` 的参数必须配 `invMap`
- `frame()` 有 `try/catch`，rAF 在 `finally`；`frameError` 用引擎标准去重器
- 全部文案 `{zh, en}` 经 `t()`
- 语法门禁 + `sync_registry.py --check` + `port_drive_engine.py --check`
- **数值自检（必须实测并写进报告）**：
  - 倒立摆开环极点 = ±√(g/L)，与线性化解析值相符
  - 工具 A③：临界 Kp 随延迟的下降与相位裕度计算一致
  - 工具 B①：根轨迹穿越虚轴处的 K 与劳斯判据解析解相符
  - 工具 B③：∫ln|S|dω 的数值积分 ≈ π·p（相对误差 < 5%），且调参时守恒
  - 工具 C：燃料耗尽前后 T·ℓ/J 的变化幅度；同一随机种子两次发射逐位一致（否则存档无法复现）
